# Re : load APK 실행 및 확인 범위

[Re-load-debug.apk](Re-load-debug.apk)는 Pleos Connect 환경에서 시험하는 디버그 빌드입니다.

| 기능 | 확인 결과 |
|---|---|
| 마이크 녹음 | 팀원 테스트에서 녹음 동작을 확인했습니다. 에뮬레이터가 Windows PC의 마이크 입력을 사용한 시험입니다. |
| 서버 연결 | 팀원 테스트에서 연결 가능한 것을 확인했습니다. 녹음한 내용이 전사되어 서버에 저장되고 다시 조회되는 전체 과정은 별도로 확인해야 합니다. |
| Pleos 위치 수집 | FusedLocation으로 위치를 받는 코드를 적용했습니다. 시험 환경에서 Pleos 위치 서비스가 좌표를 제공하는지 확인하지 못해 실제 위치 업데이트는 검증 전입니다. |
| Pleos 내비게이션 | NaviHelper로 위치와 목적지 정보를 조회하는 코드를 적용했습니다. 경로 요청과 안내 화면을 확인하려면 Pleos 내비게이션 서비스와 호환되는 환경이 필요합니다. 이번 시험에서는 실제 경로 표시까지 확인하지 못했습니다. |

Windows 마이크로 녹음이 된 결과는 위치·내비게이션 서비스의 동작 여부와 별개입니다. 해당 기능은 Pleos 서비스가 동작하고 위치 입력을 줄 수 있는 에뮬레이터나 차량에서 확인할 수 있습니다.

## 실행 방법

1. APK를 내려받아 Pleos 에뮬레이터에 설치하고 앱 목록에서 Re를 엽니다.
2. 저장과 조회를 시험하려면 같은 PC의 저장소 폴더에서 서버를 실행합니다. 최초 설정은 `01-setup.cmd`, 서버 실행은 `02-start-server.cmd`입니다.
3. 에뮬레이터가 연결된 상태에서 `adb reverse tcp:8000 tcp:8000`을 실행하면 앱의 로컬 서버 요청이 PC의 8000번 포트로 전달됩니다. PC 브라우저에서 [서버 상태](http://127.0.0.1:8000/health)를 확인할 수 있습니다.
