Re — 길 위의 기억

사용자가 동의하여 남긴 짧은 음성 메모를 주행 경로·시각과 저장하고, 같은 도로 구간을 다시 지날 때 기억을 확인하는 차량용 앱 프로젝트.

현재 상태

초기 공동 세팅과 로컬 서버 연결 확인 단계입니다. Android 앱, Pleos SDK, GPS 매칭, DB, STT·LLM은 아직 구현하거나 연결하지 않았습니다. /v1/demo-card는 fixture입니다.

로컬 서버 (Windows PowerShell, Re 폴더에서)

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
  • 이미 .venv가 있으면 생성 명령을 생략합니다.
  • 가상환경 활성화 없이 전용 Python을 직접 사용하므로 실행 정책 변경이 필요 없습니다.
  • 브라우저에서 http://127.0.0.1:8000/health 및 http://127.0.0.1:8000/docs 로 확인하고, 서버 터미널에서 Ctrl+C로 종료합니다.
  • 이 주소는 PC 내부 전용이며 Emulator·차량 연결은 별도 단계입니다.

공통 규칙

- A·B는 독립 모듈로 작업하고 C는 샘플 JSON으로 화면을 시작합니다.

- GPS·메모는 같은 trip과 기기 시계로 연결합니다. WGS84, UTC, seq, elapsed_ms를 사용하며 서버 도착 시각으로 위치를 붙이지 않습니다.

- 실제·재생 경로는 source로 구분하고 AI 처리 출처는 fixture/manual/실제 제공자 등으로 명시합니다.

- 현재 trip을 과거 기억으로 매칭하지 않습니다. 거리뿐 아니라 방향·연속 경로·중복 길이를 검증합니다.

- 명시적 시작·중지, 최대 30초 녹음, 수정·삭제·동의 철회를 반영합니다. 상시 녹음은 제외합니다.

- 운전 중 민감한 기억이나 긴 원문을 자동 노출하지 않습니다.

- 실제 음성·동선·DB·키·.env·가상환경·빌드·서명 키는 Git에 넣지 않습니다. 실데이터는 private/ 또는 test-data/real/에만 보관합니다.

팀 공동 환경 준비

확인된 로컬 환경 (2026-11-06)

- Windows PC, OS 빌드 26200. CIM 조회는 접근 제한으로 실패했고 .NET·Python으로 Windows를 확인했습니다.

- Git 2.55.0.windows.4, Python 3.11.9. py는 설치 Python을 인식하지 못하므로 python 또는 .venv\Scripts\python.exe를 사용합니다.

- 상위 고구마 폴더에 커밋·remote가 없는 빈 Git 저장소가 있습니다. Re 전용 Git 초기화·GitHub 업로드는 아직 하지 않았습니다.

- Android Studio·SDK는 기본 위치에서 발견되지 않았습니다. 전체 PC 미설치 판정은 아닙니다.

GitHub 계정과 비공개 저장소 (사용자가 직접 진행)

1
브라우저에서 https://github.com 에 접속합니다. 계정이 있으면 로그인하고 없으면 Sign up을 선택합니다. 비밀번호·인증 코드·토큰은 채팅에 입력하지 않습니다.
  • 2. 우측 상단 + → New repository → Repository name Re → Private를 선택합니다.
  • README, .gitignore, License 자동 추가는 선택하지 않고 Create repository를 누릅니다.
3
생성된 HTTPS 저장소 주소만 확인합니다. 아직 파일을 올리지 않아도 됩니다. 계정·저장소 준비 후 주소를 알려주면 로컬 연결 상태를 확인합니다.
4
로컬 Git은 Re 폴더 자체를 저장소로 만들 예정입니다. 상위 빈 저장소는 삭제하지 않습니다. 초기화 전에 경계를 다시 확인합니다. Git 사용자 이름·이메일도 확인 후 설정하며 임의로 추정하지 않습니다.
5
첫 업로드 전 git status, git diff --cached로 파일을 검토하고 실제 키·음성·위치·DB가 없는지 확인합니다. push는 사용자 요청 후 진행합니다.
6
팀 초대는 GitHub 저장소 Settings → Collaborators에서 진행할 수 있습니다. 현재 초대·메시지 발송은 수행하지 않았습니다.

구조와 설치 범위

  • 현재 backend/, docs/와 루트 설정 파일만 만듭니다.
  • android-app/, backend/ai·matching·database·routes·services·tests, shared/examples/, test-data/synthetic/, design/, tools/, apk/는 필요한 작업을 시작할 때 추가합니다.
  • Python은 서버·AI용이고 Kotlin은 차량 앱용입니다.
  • B의 현재 작업에는 Android 도구 설치가 필요 없습니다.
  • SQLite는 향후 Python 기본 sqlite3로 시작할 수 있으며 현재 DB 파일은 만들지 않습니다.

OneDrive 아래 가상환경은 다른 PC와 공유·복사하지 말고 각 PC에서 재생성합니다. 동기화 충돌이 생기면 프로젝트 위치 이동을 별도로 검토합니다.
