# MVP 사양 v0.1 초안

## 목적과 범위
동의한 사용자의 최대 30초 메모를 경로·시각에 연결하고 같은 방향의 연속 도로 구간 재방문 시 회상 카드를 제공합니다.

| 순서 | 동작 | 완료 기준 |
|---|---|---|
| 1 | 주행 시작·종료 | trip_id 발급, 실제/재생 출처 표시, GPS 순서 유지 |
| 2 | 메모 동의·녹음 | 동의 전 녹음 없음, 시작·중지 명시, 30초 자동 종료 |
| 3 | 처리 | 전사·요약·목적·키워드 반환, 처리 출처와 실패 표시 |
| 4 | 저장 | 같은 trip의 기기 시각으로 메모 구간 연결, 재요청 시 중복 방지 |
| 5 | 재방문 검색 | 현재 trip 제외, 방향·연속성·중복 길이 판단 |
| 6 | 회상 카드 | 운전 중 짧고 중립적인 안내, 긴 원문은 정차 후 명시적 조작 |
| 7 | 관리 | 정차 후 수정·삭제·동의 철회, 철회 즉시 신규 녹음·처리 중단 |

동의 철회 시 연결된 음성·전사·요약·위치 연결과 대기 작업을 제거하는 흐름을 설계합니다. 실제 제공자 보관 정책은 선정 후 별도 확인합니다. 원음 보관 기간은 미정이며 정하기 전 실제 음성 수집을 시작하지 않습니다.

## 제외
상시 녹음, 다중 계정·공유, 차량 하드웨어 제어, 도로망 고정밀 매칭, 상용 운영, 고급 감정 분석. TTS·타임라인·PostGIS는 후속 후보입니다.

## 매칭 검증
합성 경로로 같은 방향 중복, 역방향, 단일 근접점, 정지 중 흔들림, GPS 누락, 현재 trip 제외를 확인합니다. 허용 거리·방향 차이·최소 중복 길이·연속 점수는 B가 시험 후 결정합니다. 샘플은 알고리즘 성공 증거가 아닙니다.

## 미결정
AI 제공자·비용, 원음 보관, 매칭 임계값, SDK 권한·버전 조합, 실제 차량 검증, 제출 일정·조건. 공식 자료 재확인 전 확정하지 않습니다.
